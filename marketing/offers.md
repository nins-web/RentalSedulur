# Offer Design — Rental Sedulur (via marketingskills/offers, Value Equation Hormozi)

## Value Equation
Value = (Dream Outcome × Perceived Likelihood) / (Time Delay × Effort)

- **Dream**: Mabar puas tanpa ribet bawa PS
- **Likelihood**: Foto real 8 unit + trigger anti bentrok + 200+ review target
- **Time Delay**: Booking 2 menit → WA langsung → antar 1 jam (Mojokerto kota)
- **Effort**: Antar gratis, stik 2 ready, bayar di tempat

## Core Offer
Sewa PS4/PS3 harian/malam/mingguan — sudah jelas

## Bonus Stack (baru)
1. Antar-jemput gratisradius 5km (value 20k)
2. Stik extra ke-3 gratis untuk mingguan (value 15k)
3. List game request (FIFA, PES, GTA) update gratis
4. Snack + minum untuk paket malam (value 10k)
Total bonus 45k → paket terasa murah

## Guarantee
"Stik ngedrift / PS error di 1 jam pertama → ganti unit langsung atau refund 100%"

## Scarcity/Urgency
- "Hanya 8 unit — weekend sering full, booking H-2"
- Countdown di card: "3 unit tersisa malam ini" (live query bookings)

## Nama Offer
"Paket Nongkrong Semalam" (malam), "Paket Libur Panjang" (mingguan), "Paket Nobar Bola" (harian event)

## Payment
DP 50k WA, pelunasan di tempat. Test cicil 2x untuk mingguan bulan depan.
